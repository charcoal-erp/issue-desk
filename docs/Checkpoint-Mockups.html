Report normalization
Every runner reports differently — JUnit XML from pytest, JSON from Playwright and Vitest, an image-diff manifest from the visual suite, a plain exit code from shell scripts. Each runner declares its report format and report path; the adapter parses it into one shape — { caseId, status, durationMs, message, stack, artifacts[] } — matched back to a Checkpoint case by its test identifier. That is why one run can span pytest, Playwright and a shell script and still produce a single pass rate and a single failure export.
